Paper pages — the 3D stack

0.030

Every page floats the same distance from the next, so turning the model shows which page is in front. Move pages up or down to change the stack. The paper GLB and the Finish set use this order and distance.

Loaded layers

Layers loaded onto a single image stack on top of it, in the order they were loaded. The rig points belong to the base image. Save and Finish include every loaded layer as its own page.

Save the rig data

The saved file holds every point: its label, its description, its pin, what it connects to, its limits, and its blacklisted angles. Give that file back and the model gets built from it.

Paper doll - build from three pictures

Pick the man's front, back, and side pictures in one pick. The editor cuts them out clean, splits them into parts, completes the parts and grows their buffers, writes the rig points into the paper GLB, and assembles the 3D paper model - then generates the walk page from that GLB. It says what it is doing while it works, and downloads the 3D GLB, the walk page, and the full stitch set.
