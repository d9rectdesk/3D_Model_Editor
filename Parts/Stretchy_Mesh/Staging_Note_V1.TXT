WHAT IT DOES FOR THE RIG WORK
On the 2D route each full part layer needs a mesh before it
can bend or be posed: this module traces the part's own
silhouette (dilated 2 px so mesh edges land just outside the
artwork, where the texture's own alpha clips them) and
triangulates it. It is a pure module set - no DOM, no
globals - designed by its author to run on the main thread
or in a worker, which is how the editor will call it.
